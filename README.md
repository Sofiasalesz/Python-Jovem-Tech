# 💻 Projeto Python — Tech Jovem

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte das atividades do programa **Tech Jovem**, com o objetivo de colocar em prática os conhecimentos adquiridos na área de programação e tecnologia.

Utilizando a linguagem Python, o projeto busca desenvolver habilidades de raciocínio lógico, resolução de problemas e criação de soluções tecnológicas.

## 🎯 Objetivos

- Aplicar os conceitos básicos da linguagem Python.
- Desenvolver o raciocínio lógico e a criatividade.
- Aprender a criar e organizar projetos de programação.
- Adquirir experiência prática na área de tecnologia.

## 🛠️ Tecnologias utilizadas

- **Python 3** — linguagem de programação.
- **Git e GitHub** — para versionamento e compartilhamento do projeto.

## ⚙️ Como executar o projeto

1. Instale o Python 3 em seu computador.
2. Faça o download ou clone este repositório.
3. Abra a pasta do projeto no terminal.
4. Execute o arquivo principal:

```bash
python main.py
```

## 📚 Aprendizados

Durante o desenvolvimento, são trabalhados conceitos de lógica de programação, variáveis, estruturas condicionais, estruturas de repetição e funções, conforme as necessidades do projeto.
